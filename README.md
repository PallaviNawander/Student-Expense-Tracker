# 💸 Student Expense Tracker

A simple and user-friendly expense tracking application designed to help students manage their daily spending, monitor expenses, and develop better financial habits.

🔗 **Live Demo:** [Student Expense Tracker](https://pallavinawander.github.io/Student-Expense-Tracker/)

📂 **Repository:** [GitHub Repository](https://github.com/PallaviNawander/Student-Expense-Tracker)

---

## 📌 About the Project

Managing money can be challenging for students who need to balance their pocket money or monthly allowance across food, transportation, education, shopping, and other everyday expenses.

The **Student Expense Tracker** aims to make expense management easier by providing a convenient digital solution for keeping track of spending.

The project is built using Flutter and is deployed as a web application, making it accessible through a browser.

### 🎯 Objectives

- Simplify daily expense tracking.
- Help students understand their spending habits.
- Make expense management more convenient and organized.
- Encourage financial awareness and responsible spending.
- Build practical experience in Flutter application development.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Dart SDK](https://dart.dev/get-dart)
- [Git](https://git-scm.com/)
- [Visual Studio Code](https://code.visualstudio.com/) or another compatible IDE

### 1. Clone the Repository

```bash
git clone https://github.com/PallaviNawander/Student-Expense-Tracker.git
```

### 2. Navigate to the Project Directory

```bash
cd Student-Expense-Tracker
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the Application

To run the application on a connected device or configured emulator:

```bash
flutter run
```

To run it in a web browser:

```bash
flutter run -d chrome
```

**Note:** Ensure that Flutter web support is enabled and Chrome is available if you want to run the application in a browser.

## 💡 Why This Project?

Students often make several small purchases throughout the day without realizing how much they spend over time.

This project explores how a simple digital application can make personal expense management more accessible and encourage students to become more conscious of their financial decisions.

It also provides practical experience with Flutter, Dart, application structure, and deploying a project for web access.
